校验下载

每个文件都提供 SHA-256。下载完成后先核对哈希，确认文件完整再安装。

快速校验

macOS

shasum -a 256 <文件名>

Linux

sha256sum <文件名>

Windows PowerShell

Get-FileHash .\<文件名> -Algorithm SHA256

关于这个镜像

  • 清单由维护者手动运行发布脚本生成，不设自动更新，版本可能略晚于官方。
  • 下载链接指向 GitHub Releases 中的固定版本资产，不经过第三方代理。
  • GitHub 单文件上限为 2 GiB；接近上限的离线安装包会在发布前按大小与 SHA-256 严格校验。

非官方镜像，与 Anthropic 无隶属关系。请优先从官方源下载。
